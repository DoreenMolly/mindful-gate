# Mindful Gate

Screen time apps don't work for me anymore. I extend the time with no hesitation, I don't even think about it anymore. I needed something more. I needed to see what is at stake with every "five more minutes" so i made this project.

When I open Instagram, I see a picture in my vision board first. It's a reminder that nothing is free, and I am trading a dream for five more minuites. It includes an iPhone SHortcut, a Chrome extension, and a Python analysis of my usage logs.
